# Contrib

Utilities kept for building and operating Spectre:

- **[devtools/](devtools/)** — security/symbol checks, man page generation
- **[docker/](docker/)** — containerized node
- **[macdeploy/](macdeploy/)** — macOS packaging helpers
- **[seeds/](seeds/)** — generate seed-node lists for a new network

Removed upstream-only tooling (gitian, debian packaging, Zcash metrics) to keep the repo lean.
